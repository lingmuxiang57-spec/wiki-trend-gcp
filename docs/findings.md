# ダッシュボードから読み取れるトレンド

対象：英語版 Wikipedia の20記事、2025-07-04〜2026-11-19 の日次閲覧数（`agent=user`）
伸び率は「直近3か月の合計 ÷ 1年前の同じ3か月の合計 − 1」（ビュー `v_yoy_ranking`）

### ① 20記事の中で、伸びているのは DuckDB だけ
- 何が：DuckDB（分析基盤）
- どのくらい：直近3か月の閲覧数は 26,688 で、1年前の同じ時期（18,710）より **+43%**。20記事のうち、プラスになったのは DuckDB だけだった
- なぜだと思うか：DuckDB は比較的新しい技術で、まだ知らない人が多く、新しく調べる人が増えている段階だと考えられる

### ② AI × データベース系の記事も、大きく減っている
- 何が：Retrieval-augmented_generation（RAG）、Vector_database
- どのくらい：
  - RAG は20記事の中で閲覧数の規模が最も大きいが、139,477 → 92,335 で **−34%**
  - Vector_database は 30,426 → 17,768 で **−42%**
- なぜだと思うか：生成AIの普及とともに一時的に注目が集まったが、そのブームが落ち着いてきたためと考えられる

### ③ DuckDB の閲覧数が、2026-08-26 に約10倍に跳ねた
- 何が：DuckDB の日次閲覧数
- どのくらい：
  - 2026-08-26 に **1,960**。前の週の平均（約200）の **約10倍**
  - 翌日の 08-27 も 1,829 と高く、08-28 は 727 に下がった
  - その後は 400 前後で推移しており、急上昇の前（200 前後）の約2倍の水準になった
- なぜだと思うか：新しいバージョンのリリースやニュースで、一時的に話題になったためと考えられる。高い値は2日でほぼ収まったので、一時的な関心の高まりと読み取れる。ただし、その後の水準も上がっているので、話題をきっかけに継続して調べる人が増えた可能性もある。この動きは①の「DuckDB だけが伸びている」こととも合っている
